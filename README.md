# Line Production · لاين برودكشن

Wedding and event planning website (Arabic + English), Taif Rose identity.

Live site: **https://line-production.github.io**

---

## How to edit the site (English)

Everything is in one file: `index.html`.

1. Open `index.html` in this repository and click the **pencil icon** (Edit).
2. Press **Ctrl+F** (Cmd+F on Mac) and search for the text you want to change.
3. Change only the words. Leave the code around them (`<`, `>`, `"`, `data-t=...`) as it is.
4. Click **Commit changes**. The live site updates in about one minute.

The site has two languages. English text sits in the page itself; Arabic text sits in a list near the bottom of the file that starts with `const AR={`. When you change something, change it in both places.

### Made a mistake?

Open the **commits** list of this repository (the clock icon), pick the last version that worked, open `index.html` there, copy it, and paste it back into the current file. Nothing is ever lost.

## طريقة تعديل الموقع (عربي)

كل محتوى الموقع موجود في ملف واحد: `index.html`.

1. افتح ملف `index.html` في هذا المستودع واضغط على **أيقونة القلم** (تعديل).
2. اضغط **Ctrl+F** (أو Cmd+F على ماك) وابحث عن النص الذي تريد تغييره.
3. غيّر الكلمات فقط، واترك الرموز حولها كما هي (`<` و`>` و`"` و`data-t=...`).
4. اضغط **Commit changes**، وسيتحدّث الموقع تلقائياً خلال دقيقة تقريباً.

الموقع بلغتين: النص الإنجليزي داخل الصفحة نفسها، والنص العربي في قائمة قرب نهاية الملف تبدأ بـ `const AR={`. عند تغيير أي معلومة، غيّرها في المكانين.
